# AI Invoice Assistant (Enterprise Edition)

An enterprise-grade AI Invoice Assistant built using modern web technologies and the OpenAI Responses API.

## Tech Stack

### Frontend
- React
- Vite
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express
- TypeScript

### AI
- OpenAI Responses API

### Database
- SQLite

### Features (Planned)

- Upload Invoice PDF
- Extract Invoice Text
- AI Summary
- Chat with Invoice
- OCR Support
- RAG
- Authentication
- Audit Logs

🚧 Currently under active development.
